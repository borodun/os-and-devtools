# Заметки предыдущего админа

* Формат лога: `[время] [СОБЫТИЕ] ник: текст`.
  События: JOIN, LEAVE, CHAT, BREAK (копка блоков), GRIEF (разрушение), SYSTEM.
* В логе есть строки с **пустым ником** — это баг NULL-входа
  (логин без ника). Тот нарушитель уже заблокирован по IP; в списки
  ников, которые нужно забанить, его не включать.
* `grep -c УЗОР файл` — количество строк по узору;
  `grep -f файл_с_узорами файл` — узоры берутся из файла (по одному на строку);
  так удобно выгрузить сразу все строки по списку ников.
* `cut -d' ' -f3 file` — вырезать поле по разделителю (`-d` — разделитель,
  `-f` — номер поля); так из строк лога легко получить список ников.
* `sort file | uniq` — отсортировать и убрать дубликаты.
* `find . -name 'имя_файла'` — найти файл по имени в текущем
  каталоге и во всех подкаталогах (полезно, когда файл «потерян»).
* В grep: `^` и `$` — начало и конец строки; `sed 's/старое/новое/'` — замена.
* `users/backup-index.txt` — манифест бэкапа: список файлов мира
  с их правильными путями.
